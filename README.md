# 哦鲸鲸翻译

按住 Alt 划一下英文，鼠标旁边直接浮出中文。

一个 Windows 桌面小工具：在**任何程序**里（浏览器、PDF 阅读器、Word、微信……）按住 `Alt` 拖选英文，松手立刻在鼠标旁弹出中文译文。译文边生成边显示，不用等整段写完。

翻译由**网页版 DeepSeek** 完成——程序在后台用内嵌浏览器驱动 `chat.deepseek.com`，和你在浏览器里用的是同一个免费网页版，**不需要 API Key，不产生费用**。

> 图标形象来自 DSH 的「余额小挂件」插件。

## 特性

- **全局划词**：任意程序里都能用，不限于浏览器
- **按住 Alt 才触发**：不打扰正常的选择、拖拽、复制
- **流式显示**：第一行通常 3~4 秒就出来，不必等整段生成
- **不挡原文**：浮层巴掌大一块，原文只占一行
- **自动读选区**：优先用系统无障碍接口（UI Automation）直接取词，取不到才临时模拟 `Ctrl+C` 并还原剪贴板
- **绿色版**：不写注册表、不开机自启，删文件夹即卸载
- **不需要 API Key**：走网页版，登录一次，登录态留在本地

## 系统要求

- Windows 10 1903+ / Windows 11，64 位
- .NET Framework 4.8（系统自带）
- WebView2 运行时（Win10 1803 之后通常已具备；缺了可装 Evergreen Runtime）

## 编译

需要 **.NET Framework 4.8 自带的 csc**，语言级别受限在 **C# 5**（不能字符串插值、不能 `?.`、`catch` 里不能 `await`）。

```bat
build.cmd
```

产物：`out\WordTranslator.exe`。脚本最后会无条件执行一次

```bat
icacls out\WordTranslator.exe /setintegritylevel Medium
```

**这一步不能省**：在被沙箱/受限环境里编译出来的 exe 会带 `Low` 完整性标签，进程一启动就是受限进程——全局钩子装不上、写不了用户目录、WebView2 初始化报 `0x8000FFFF`。看起来像“代码有 bug”，实际是文件标签。

## 使用

1. 双击 `WordTranslator.exe` → 弹出 DeepSeek 窗口，登录账号（只需一次）
2. 登录后窗口收起，托盘出现小鲸鱼图标，状态变「就绪」
3. 任意程序里：按住 `Alt` → 划选英文 → 松手
4. 译文出现在鼠标旁；点一下浮层可固定，`Esc` 关闭

托盘菜单里还有：翻译剪贴板内容、重新登录、显示 DeepSeek 窗口（调试）、设置（轮数重置 / 请求间隔 / 译文字号 / 自动隐藏 / 是否显示原文 / 前缀）、打开日志目录。

## 工作原理

```
Alt + 划选
   ↓  全局键鼠钩子 WH_KEYBOARD_LL / WH_MOUSE_LL
UIA 取选区文本（失败则模拟 Ctrl+C 并还原剪贴板）
   ↓
内嵌 WebView2 打开 chat.deepseek.com（复用本地登录态）
   ↓  注入脚本：写入输入框 → 点发送 → 轮询 DOM
检测到回答开始输出即回流（流式）
   ↓
浮层逐字显示中文
```

DeepSeek 网页改版时，**只需要改 `src\PageSelectors.cs` 一个文件**（输入框、发送按钮、流式标记、回答容器的选择器都集中在这里）。程序启动时会做页面自检，认不出结构会在托盘提示。

## 数据与隐私

- 运行数据存在 exe 同目录的 `哦鲸鲸翻译Data\`（目录不可写时改用 `%LOCALAPPDATA%\哦鲸鲸翻译\`）：
  - `wv2\` 浏览器登录态，删掉需要重新登录
  - `settings.json` 设置
  - `logs\app.log` 日志
- **`data\` 目录含 DeepSeek 登录 Cookie，已在 `.gitignore` 中排除，永远不要提交。**
- 程序只把选中的文本发给你登录的 DeepSeek 网页，不经过任何第三方服务器。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 划词没反应 | 确认托盘状态是「就绪」；必须**按住 Alt 再拖选**；选中内容要像英文 |
| 提示「未登录」 | 托盘 → 重新登录 DeepSeek |
| 「没有拿到译文（页面结构可能变了）」 | 网页改版，需要更新 `PageSelectors.cs`，带上日志提 issue |
| 「页面自检未通过」 | 同上，启动时的结构自检没通过 |
| 「引擎重启中…就绪（已自动重启）」 | 内嵌浏览器进程崩了，程序会自动重建，不用重新登录 |
| 杀毒软件报警 | 程序带全局钩子 + 内嵌浏览器 + 联网，行为特征确实像监控软件，属正常功能；可加信任或丢虚拟机跑 |
