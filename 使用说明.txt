哦鲸鲸翻译 v0.1
================

一个 Windows 小工具：按住 Alt 用鼠标划选英文，鼠标旁边立刻弹出中文译文。
翻译由网页版 DeepSeek 完成（程序在后台驱动 chat.deepseek.com，和你在浏览器里用的是同一个免费网页版）。
译文是一边生成一边显示的，不用等整段写完。


一、解压后怎么用
----------------
文件夹里有两个文件：

  哦鲸鲸翻译-v0.1.exe  ← 双击这个就行（图标是小鲸鱼）
  使用说明.txt         ← 就是本文件

整个文件夹可以放在任何位置（例如 D:\工具\哦鲸鲸翻译\），解压到哪都能用：
运行数据存在 exe 同目录的「哦鲸鲸翻译Data」里，不开机自启、不写注册表。

第一次启动：

1. 双击 哦鲸鲸翻译.exe → 会弹出 DeepSeek 窗口，在里面登录你的账号（只需一次，登录状态会记住）。
2. 登录成功后窗口自动收起，右下角托盘出现小鲸鱼图标。
3. 在任意程序里：按住 Alt → 用鼠标划选英文 → 松手。
4. 译文出现在鼠标旁边，点一下可以固定住不自动消失。

注意：DeepSeek 窗口右上角有关闭按钮，点它只是把窗口收起来（程序继续在后台跑），不会退出程序。要退出请用托盘菜单。


二、托盘菜单
------------
- 状态：显示当前引擎状态（启动中 / 未登录 / 就绪）。
- 翻译剪贴板内容：不想划词时，先复制一段英文，点这个也能翻译（调试用）。
- 重新登录 DeepSeek：登录过期时点它，会重新弹出窗口。
- 显示 DeepSeek 窗口（调试）：把后台页面显示出来，出问题时方便看页面状态。窗口右上角可以关闭，关掉只是收起，不影响翻译。
- 设置：翻译轮数重置、请求间隔、译文字号、自动隐藏、是否在浮层里显示原文、发送给网页版的前缀。
- 打开日志目录：排查问题用。
- 退出。


三、浮层说明
------------
- 原文只占一行，太长会用省略号截断，把空间留给译文。
- 觉得原文占地方：设置里取消勾选「在浮层里显示原文」，就只看中文。
- 点浮层 = 固定（不再自动消失）；按 Esc 关闭；鼠标移开自动消失（可在设置里调秒数）。


四、常见问题
------------
Q: 划词没反应？
   - 确认托盘图标在，且状态是「就绪」。
   - 必须按住 Alt 再拖选，只是点一下或普通拖动不会触发。
   - 选中的内容要像英文（字母占多数）。

Q: 提示「未登录」？
   - 托盘 → 重新登录 DeepSeek，在弹出的窗口里登录。

Q: 提示「网页版没有开始响应」？
   - 可能是 DeepSeek 限流或网络问题，等一会儿再试。
   - 也可以点「显示 DeepSeek 窗口」看看页面是不是卡住了。

Q: 提示「没有拿到译文（页面结构可能变了）」？
   - DeepSeek 网页改版了，需要更新程序里的页面选择器。把日志发给我即可。

Q: 右下角提示「页面自检未通过」？
   - 程序每次启动都会检查还能不能认出 DeepSeek 页面（输入框、发送按钮、开关）。
     提示这个说明页面结构变了，可能翻译会失败；把日志发给我，改一个文件就能修好。

Q: 状态突然变成「引擎重启中…」然后「就绪（已自动重启）」？
   - 内嵌的浏览器进程崩溃了，程序会自动重建引擎（约 3 秒），不用手动重启，也不用重新登录。

Q: 翻译要等好几秒？
   - 正常。网页版要先「思考」再输出，通常 3~6 秒；现在是一边出字一边显示，不用等全部写完。

Q: 杀毒软件报警？
   - 程序会模拟 Ctrl+C 读选区、带一个浏览器内核、会联网，行为上确实像"监控类"软件。
   - 这是正常功能所需，可加入信任；不放心的也可以在虚拟机里跑。

Q: 会覆盖我的剪贴板吗？
   - 优先用系统无障碍接口直接读选区，不动剪贴板；只有取不到时才临时模拟 Ctrl+C，并且会还原原来的剪贴板内容。

Q: 同时开两个会怎样？
   - 只允许开一个，第二个会提示「已经在运行了」。


五、数据与卸载
--------------
数据默认放在 exe 同目录的「哦鲸鲸翻译Data」里（绿色版，整个文件夹拷走就带走登录态）：
  - logs\app.log  日志
  - wv2\          浏览器登录态（删掉就要重新登录）
  - settings.json 设置

如果 exe 所在目录不可写（例如放在 Program Files），会自动改用 %LOCALAPPDATA%\哦鲸鲸翻译\。

卸载：托盘退出 → 删除整个文件夹即可，不写注册表、不开机自启。


六、系统要求
------------
- Windows 10 1903 及以上 / Windows 11（需要系统自带 .NET Framework 4.8 与 WebView2 运行时，通常都已具备）。
- 64 位系统。

图标形象来自 DSH 的「余额小挂件」插件（小鲸鱼）。
